# Dealerships and Customer Reviews Platform

A full-stack cloud web application for a national car retailer network in the United States, developed as part of the IBM Full Stack Software Developer Capstone Project.

## Project Overview
This application provides customers and administrators with:
- Dealership branch lookup by state and ID across North America
- Customer review submission and inspection with IBM Watson Natural Language Understanding Sentiment Analysis
- Django and SQLite user authentication, session management, and car inventory models
- Node.js and Express MongoDB microservices backend
- Modern dynamic React frontend components
- Continuous Integration & Deployment (CI/CD) pipelines with GitHub Actions and IBM Cloud Code Engine containerization

## Architecture & Technologies
- **Frontend:** React, HTML5, CSS3, Bootstrap 5
- **Core Backend:** Python, Django 4.2, SQLite
- **Microservices:** Node.js, Express, MongoDB (Docker containerized)
- **Sentiment Analysis:** Python, Flask, IBM Watson / NLTK
- **DevOps & Cloud:** Docker, Kubernetes, IBM Cloud Code Engine, GitHub Actions
